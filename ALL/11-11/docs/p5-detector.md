# P5 检测器评测口径

> 状态：未开始，先把口径定下来，避免后面返工。

## 两个检测器

| 检测器 | 触发方式 | 判定信号 |
|---|---|---|
| Go 运行时死锁检测 | 直接运行，不加参数 | 打印 `all goroutines are asleep - deadlock!` 后退出 |
| `-race` | `go build -race` / `go test -race` | 打印 `WARNING: DATA RACE` |

## 统计口径

- 分母：已复现的 bug 条数，按阻塞/非阻塞分组
- 分子：至少一次运行中出现判定信号的条数
- `-race` 每条约 100 次，同时记录「第几次首次检出」

## 已知约束

- 概率型 bug 单次跑不出不代表检不出，样本量不足时只能写方向一致
- 论文的 deadlock detector 只检出 21 条中的 2 条，我们的样本远小于 21，
  复现结论要注明缩小规模
