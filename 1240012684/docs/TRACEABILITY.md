# Traceability: every reported number -> a file in this repository

Regenerate the derived artefacts at any time with:

```bash
make run      # re-runs everything, overwrites results/
make analyze  # recomputes statistics.csv, tables and figures from summary.csv
make report   # rebuilds report/report.pdf
```

`results/summary.csv` is the primary raw measurement: one row per trial,
written directly by `scripts/run_experiments.sh`. Columns:
`mode, run, exit_code, wall_clock_ms, deadlock_reported, timed_out,
last_trace_ms, result_line, log_file`.

## Chain of custody

```
third_party/bolt (pinned commit)
        |
        v
scripts/run_experiments.sh  ->  results/raw/*.log  (41 logs, never edited)
        |                              |
        |                              v
        +----------------------> results/summary.csv
                                       |
                                       v
                     scripts/analyze.py -> results/statistics.csv
                                       -> results/table_*.md
                                       -> results/figures/*.svg
                                                |
                                                v
                          scripts/make_report.py -> report/report.pdf
```
